# addons/terrain_tools
What: the editor's tools for a map's ground, whose only source is `heights.png` (16 bits, x 0.1 m) + `void.png` beside it: the importer (`TerrainHeights`), the buttons in a `Terrain`'s inspector and the ground brush of the 3D viewport. Dev only (the export excludes it).
Not: what the ground is or does in a match (scenes/map/terrain), the Blender scripts themselves (tools/blender), checking a map (tools/audit/map_checks.gd).
Talks to: `plugin.gd` wires it. Inspector: `TerrainPanel` -> `TerrainActions` -> `BlenderBridge`, `TerrainEdits`, `MapChecks`. Brush (one path for every canvas): `BrushPainter` (mouse; picks on the map Terrain's heights with `GroundPick`, `BrushCursor`) -> `BrushTargets` (selected node + bar tool -> canvas and mode) -> `BrushStroke` on a `BrushCanvas` working copy; `LatticeCanvas` = heights + void (`BrushRules`, preview `EditorPreview`: global `terrain_deform_map`, no mesh rebuild per move); pictures use `PaintRules`, `BrushCanvas.PixelPatch` and `CanvasFiles` (roles canvas: 066c; `DensityCanvas` = a `FloraLayer`'s density PNG, preview `FloraLayer.show_painting` -> `FloraField.layer_painted` replants only that area; `TerrainHistory.density` makes the PNG of a layer without one as its own undo step). Release -> `TerrainHistory.commit` (one undo step on the canvas's node; the lattice hands its patches to the `TerrainHeights`, or keeps a draft when the rebuild is heavy per `RefreshBudget` until save or «Rearmar»). Ctrl+S -> `TerrainHistory.save` saves every dirty canvas (writes its file, reimports).
Edit: the brush preset `brush/default_brush.tres` (size, falloff, shape, strength, flow, density; another preset = another `.tres`); the bar `brush/brush_toolbar.tscn`; `RefreshBudget.LIMIT_MS` (300 ms); `MapGroundChecks.MAX_SPREAD_M` for «base a nivel».
Check: `debug/terrain/edit_bed.tscn` (open it, select `Terrain`) · `debug/terrain/paint_bed.tscn` (roles and flora bed: select `Terrain` or `Vegetation/Ferns`) · `debug/terrain/roundtrip_cases.tscn` (headless, ROUNDTRIP CASES PASS) · `debug/terrain/brush_cases.gd` · `debug/terrain/paint_cases.gd` (headless, PAINT CASES PASS) · `debug/terrain/density_cases.gd` (headless, DENSITY CASES PASS) · `bash agent/harness/godot_run.sh bash agent/scripts/terrain_brush_probe.sh` (editor window: strokes, undo, save, refresh times) · `agent/runs/run_terrain_blender.sh`.

---

How a human uses it (open the map scene, select its `Terrain` node):
- **Paint the relief:** the bar «Terreno:» appears over the 3D view (groups Relieve and Roles; with a `FloraLayer` selected it says «Flora:»; Roles and Flora paint from 066c/066d on). Pick «Subir/Bajar» and drag the mouse up (raise) or down (lower) where you pressed; «Suavizar» drag (Shift: flatten to the height where the stroke began); «Hueco» paints void (Shift: fills it back with the old height). «Tamaño», «Caída», «Forma» and «Fuerza» are the shared brush. The ring on the ground is the brush. Ctrl+Z / Ctrl+Shift+Z undo and redo a stroke. Ctrl+S writes heights.png and void.png. On a map whose rebuild takes more than 300 ms (the bar says «al guardar»), strokes show through the preview and the mesh is built on save or with «Rearmar».
- **Paint flora:** select a `FloraLayer` under the map's `Vegetation` (it needs its species), «Flora» in the bar and drag: plants grow live where you paint, Shift erases. «Densidad» is how full a dab leaves it (1 = `max_per_cell`), «Flujo» how fast it gets there. A layer without a picture gets `<map>/flora/<node_name>.png` (320² L8 at 8 m, blank) on the first click, as its own undo step «Flora: imagen nueva». Ctrl+Z undoes a stroke, Ctrl+S writes the PNG. The same PNG can still be painted in Krita or any image editor (white = dense).
- **Blender:** «Abrir en Blender» saves what is pending, makes `terrain_work/terrain.blend` and opens Blender (Blender from `BLENDER` or the PATH; without one it says how). Move vertices only in Z, paint the group «void», save in Blender, then «Traer de Blender»: it writes the pictures and reimports, or says why it refused (and offers to skip the «pictures changed» guard). Not undoable.
- **New ground:** set the height and press «Suelo plano nuevo» (asks first; not undoable).
- **New map:** Proyecto → Herramientas → «Mapa nuevo…», a tag (`mi_mapa`) and a name, «Crear». `new_map/` copies `scenes/map/maps/_template/` (`NewMapFiles`), imports, opens the scene, bakes its navmesh (`MapNavRegion.bake_now`) and runs «Validar mapa» (`NewMapAction`); the dialog says live why a tag is refused. Check: `debug/terrain/new_map_cases.gd` (headless, NEW MAP CASES PASS) · `bash agent/harness/godot_run.sh bash agent/scripts/new_map_probe.sh` (editor window).
- **Bases:** «Aplanar bases» levels the land under every `GroundFootprint` (altars, founts) to the median height under it; Ctrl+Z undoes it.
- **Check:** «Validar mapa» runs the check_map logic on the open map and shows PASS or every problem with the node's path. Bake the navmesh (NavRegion) after changing the shape.
