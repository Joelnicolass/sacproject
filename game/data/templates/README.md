# data/templates/

Plantillas que copian las herramientas al crear contenido nuevo (no entran al catalogo: `GameCatalog` solo escanea `data/catalog/`).

- `creature.tres`: stats base de una criatura nueva (`tools/bake/new_creature.gd`). Cambialos aca para cambiar el punto de partida de las criaturas que se creen despues; las que ya existen no se tocan.
