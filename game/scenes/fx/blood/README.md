# fx/blood
What: every creature and wizard that loses health bleeds red: `BloodFx` (a child of unit.tscn, wizard_body.tscn and doctor.tscn) hears `Health.changed` on the server, decides the wound and writes `BloodFx.wound` (replicated); every peer, on a new wound, plays the `BloodType` spray at the body's CENTER and asks `GroundScars` for `blud` marks at the server's FEET, drawn from the match seed so every peer paints the same (permanent, in the «Cantidad de marcas» pool). `SprayMarks` (one in match.tscn) paints a pool of 12 marks where the gib's spray (data/fx/blood.tres) plays. `HitFlash` (next to BloodFx) blinks the body's meshes 0.12 s with an additive `material_overlay`.
Not: the simulation (nothing here writes it, no RPC; headless/dedicated only decides `wound`, draws nothing), who bursts (Gib), who owns the marks (GroundScars), buildings.
Talks to: Health.changed (server) -> BloodFx -> BloodRules.kind_for (none / light / heavy) -> `wound` (MultiplayerSynchronizer) -> every peer: FxBus.play(spray) + GroundScars.of(self).stamp(mark); Health.changed -> HitFlash -> material_overlay + instance uniform `hit_flash` (tween, then off; never in stealth or faded); FxBus.played(blood.tres) -> SprayMarks -> stamp ×12; the look's `BodyLook.blood` or BloodFx `fallback` picks the type.
