# look/atmosphere

What: the hour and the weather of now, as one `AtmosphereSample` (`Atmosphere.changed`): the sun turns into the moon at night, the ambient, fog and sky dim and tint, stars and moon show; in a storm lightning strikes 150-600 m from the camera (the same instant and heading for everyone, ≥ 4 s apart) with a short sky flash and the thunder later. At the start hour, with Clear, it is neutral: the approved look, byte for byte.
Not: who writes the light (SunLayer), the Environment and the sky (EnvironmentLayer, through SkyDresser), the ambient life (look/life); nothing here touches the simulation.
Talks to: BiomeLink (scenes/net/) sends `MatchSky.message()` (server seconds + sky seed) in the biome message -> `Atmosphere` reads `MatchSky.now_s()` -> `TimeOfDay` (DayCycle) and `Weather` (WeatherPlan + seed; tells `Precipitation` what falls and `Storm` the ruling weather: StormStrikes asks `AtmosphereRules.strikes_between`, draws each strike with FxBus (bolt, flash with its light from FxLightLayer), plays the thunder by SoundBus `distance / 343` s later and returns the flash, which goes in the sample) -> `changed(sample)` -> SunLayer / EnvironmentLayer / AmbientLifeLayer. Events: `hour_changed(hour)`, `night_changed(is_night)`, `Weather.weather_changed(from, to)`, `Weather.strike(at)`. Loading screen (069): `Weather/WarmHook` -> `Weather.warm` -> each rain or snow of the plan `PrecipitationFall.flash`es for one frame, silent (the bolt is FxBus's hook); the drops are set up stopped and then restarted (a running emitter given another material kept no uniform set) and their `Follow` always processes, so they fall around the camera while the start gate pauses the tree.
Edit: `data/look/<god>.tres` -> Day (curves over 0..24 h; at `start_hour` multipliers 1 and amounts 0; the night colors are near white so a pale ground darkens instead of turning blue) · `data/look/weather/<state>.tres` (a new weather = duplicate one, add a chance to `plan.tres`, which all five gods share; `shadow_mul` makes the sun's shadows faint and soft under a cloudy sky, `sun_tint` cools its light, `fog_clear_m` keeps the fog off the play so a mist hides only the far land, `sky_grey` takes the color out of the sky and the fog) · in a `map.tscn` select `Look/Layers/Atmosphere` and set `preview_hour` / `preview_weather` (with `Look.preview_god` set). Lightning: `Weather/Storm` in `atmosphere.tscn` (distances, `min_gap_s`, `bolt_top_m`, `flash_s`, `flash_scale`) · `storm.tres` (`strikes_per_min`, `flash_strength`) · `data/fx/beams/storm_bolt.tres`, `data/fx/storm_flash.tres`, `data/audio/cues/thunder.tres`. Hide `Atmosphere` = neutral.
Check: F6 `debug/look/ambience_lab.tscn` (a day in 24 s; KP0 toggles the layer) · F6 `debug/look/storm_lab.tscn` (storm all the time) · `rules_suite` ATMOSPHERE cases (`strikes_split` for the lightning) · `bash agent/runs/run_058_sync.sh` (dedicated + A + B that drops and comes back: same sky) · `--log=atmosphere` prints `atmosfera t=… hora=… clima=…` every 10 s and `atmosfera semilla <n>`, and `rayo t=… rumbo=… dist=…` per strike.

---

Events for a future rules node. The weather is presentation only, but its state is not hidden in the look: the dedicated server builds no `Atmosphere`, yet `MatchSky` runs there too (MatchBiome begins it), so a rules node subscribes without a redesign by deriving the same state on any peer:

- hour: `AtmosphereRules.hour_at(god.look.day, MatchSky.now_s())`, night: `AtmosphereRules.is_night(...)`;
- weather: `AtmosphereRules.state_at(god.look.weather, MatchSky.sky_seed(), MatchSky.now_s())`.

On a peer with a screen the same moments arrive as signals: `Atmosphere.hour_changed`, `Atmosphere.night_changed`, and on `Weather` (058-2) `weather_changed(from, to)` and `strike(at)`; the strikes themselves are `AtmosphereRules.strikes_between(MatchSky.sky_seed(), t0, t1, state.strikes_per_min)`, the same on the server. `time_scale` and `frozen_hour` are debug only: in a networked match they must stay 1 and -1, or the peers disagree.
