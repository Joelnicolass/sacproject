# map/nav
What: the map's walkable surface. The map keeps one navmesh (`nav.res`, the one the region and every query use), but it is baked and kept in pieces: `NavZones` cuts the footprint in a fixed grid of squares from (0, 0) (`zone_m` 160 m, 16 x 16 on 2560 m), bakes each square with a box of the square plus `zone_border_m` (8 m) and a fixed height (`floor_m` to `ceiling_m`), and joins the pieces (vertices rounded to a tenth of a cell, always in zone order) into one navmesh. The pieces meet exactly on the zone lines, so baking again only the zones a change touches gives the same navmesh as baking all of them. `zones_touching(rect)` says which zones a change touches, `baked(geometry, zones)` bakes those (several at once on the worker pool) and shares the rest, `split` cuts a saved navmesh into pieces, `stitched` gives the joined one. `NavBakeSettings` (`data/nav/nav_bake.tres`) holds every number of the bake. `MapNavRegion` is the map's `NavigationRegion3D` (the «Hornear navmesh» button, a warning when the navmesh is stale or a number is wrong). `NavRegions` indexes the walkable pieces, `NavFingerprint` hashes the source, `NavMeshBackend` answers paths, `NavBoxBlockers`, `PathFollower`.
Not: when to bake again or what changed (`NavService`, `NavChanges`, `NavRebake`), what the AI does with a path, how the ground moves (map/terrain).
Talks to: `tools/bake/bake_nav.gd` bakes all zones and saves the joined navmesh; `NavRebake` bakes the touched zones in a match and swaps the result in. The region has `use_edge_connections` off (the zone lines already meet exactly; on, each swap costs ~850 ms on the main thread instead of ~25 ms); `NavRegions` joins the sides that overlap anyway.
Edit: `data/nav/nav_bake.tres`: `zone_m`, `zone_border_m` (multiples of `cell_size`), `floor_m`/`ceiling_m` (the lowest ground and the highest roof of any map), the agent numbers. The map scene's `NavRegion`: `use_edge_connections` off. Bake with «Hornear navmesh» on the region or `"$GODOT" --headless --path game res://tools/bake/bake_nav.tscn -- --map=<tag>`.
Check: `bake_nav.tscn -- --map=<tag> --check` (twice: same hash)
