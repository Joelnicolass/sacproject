# scenes/net/

Glue de red de Sacrifice sobre `addons/mp_kit`: servidor de salas, host local, tickets. Nada generico de red va aca.

Agregar uno nuevo: poner el script y la escena aca, componer con nodos hijos y `@export` (nada de herencia profunda), y los datos de tipo en `data/` como `.tres`. Las pruebas de este dominio van en `debug/net/`.
