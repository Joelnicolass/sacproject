# spells/carrier

Something a spell sends on a trip: one `SpellCarrier` whose `motion` is SOUL_TRIP (Soul Mole, Soul Wind), GUIDED
(Dragonfire, Charm, Blind Rage, Vaporization), FALL (Bovine Intervention) or HUNT (Death). Its children add the rest
(`SoulFetch`, `CarrierPulse`, `ChainHop`, a `TargetEffect`, the look) and read the carrier; they never name it by path.
Another travelling spell is another carrier scene with other children.
