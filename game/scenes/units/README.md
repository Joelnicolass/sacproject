# scenes/units/

Unidades: tipos de criatura, cuerpo, cadaver, habilidades (`abilities/`), ataques, pasivas, afliciones, movimiento y puntería (`targeting/`).

Agregar uno nuevo: poner el script y la escena aca, componer con nodos hijos y `@export` (nada de herencia profunda), y los datos de tipo en `data/` como `.tres`. Las pruebas de este dominio van en `debug/units/`.
